# Marin Heđeš — Personal Website

Personal portfolio website built with Next.js, React, and TypeScript.

**Live:** [marinhedes.com](https://www.marinhedes.com) · [sincerelyfaust.com](https://sincerelyfaust.com)

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- next-themes
- pnpm

## Getting Started

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available Scripts

| Command          | Description                    |
| ---------------- | ------------------------------ |
| `pnpm dev`       | Start the development server   |
| `pnpm build`     | Build for production           |
| `pnpm start`     | Start the production server    |
| `pnpm lint`      | Run ESLint                     |
| `pnpm typecheck` | Run TypeScript checks          |
| `pnpm format`    | Format code with Prettier      |
| `pnpm check`     | Run code quality checks        |
| `pnpm analyze`   | Analyze the application bundle |
